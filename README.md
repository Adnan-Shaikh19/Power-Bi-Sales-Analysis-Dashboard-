# Power-Bi-Sales-Analysis-Dashboard-
1. Problem Statement & Objectives

    Identify key business questions answered by the dashboard:

    Which product categories drive the highest revenue and profit margins?

    What are the customer buying patterns and churn/retention trends?

    How are sales performing geographically or over specific time periods?

2. Data Pipeline & Methodology

    Data Sources:The analysis on two primary CSV datasets: a Customer Details file containing demographic and location profile data, and an Orders table              recording transactional history. These files were imported into Power BI and merged into a relational model using Customer ID as the common key to enable         cross-functional analysis.

    Data Cleaning & Transformation: Steps taken in Power Query (handling missing values, column formatting, merging tables).

    Data Modeling: Schema structure ( Star Schema with Fact and Dimension tables).

    Calculations (DAX): DAX measures created (Total Revenue, Moving Averages, Customer LTV,  ETC).

3. Dashboard Features & Visualizations

    Sales Performance View: Revenue breakdown by time, region, and sales channel.

    Customer Analytics View: Customer lifetime value, to customers spends, purchase frequency.

    Product Performance View: Profitability matrix, top 10 products, low-margin items.

4. Business Recommendations & Next Steps

    Actionable business decisions based on dashboard insights (e.g., reallocating marketing budget to top customer segments, discounting slow-moving inventory).
